# EImage

**Fast, local and open-source image converter and optimizer.**

Convert, resize, compress and clean images in batches with a simple interface.

> Free. Open source. Your images stay on your device.

## Planned features

- JPG / PNG / WebP / AVIF conversion
- Resize by dimensions or percentage
- Quality/compression controls
- Batch processing
- Crop and rotate
- Metadata removal
- Before/after size comparison
- ZIP download for batch outputs
- Local-first processing
- Light and dark themes
